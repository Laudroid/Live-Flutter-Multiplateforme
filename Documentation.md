# Cours Flutter Multiplateforme

## Objectifs de la formation

- Comprendre les fondements de Flutter et Dart
- Concevoir des interfaces utilisateurs réactives et responsive
- Gérer l'état de l'application avec setState et Provider
- Intégrer des services externes comme les API REST et Firebase
- Maîtriser la navigation et le passage de données entre écrans
- Construire, tester et publier une application mobile multiplateforme
## Séance 1 : Séance 1 : Introduction à Flutter & Dart

**Durée :** 3h

### Objectifs pédagogiques

- Comprendre les principes de base de Flutter
- Installer l’environnement de développement
- Créer un premier projet Flutter et comprendre sa structure
### Contenus

#### Introduction théorique

- Présentation de l'écosystème Flutter vs React Native/Natif
- Architecture technique : Moteur Skia et langage Dart
- Concepts fondamentaux : Widgets Stateless vs Stateful
#### Installation et Configuration

- Configuration du SDK Flutter et de l'éditeur (VS Code/Android Studio)
- Utilisation de 'flutter doctor' et gestion des émulateurs
## Séance 2 : Séance 2 : Widgets & Composition

**Durée :** 3h

### Objectifs pédagogiques

- Maîtriser les widgets de disposition (Layout)
- Comprendre l'arborescence des widgets
### Contenus

#### Théorie de la Composition

- Widgets de structure : Row, Column, Stack, Container
- Gestion de l'espace : Padding, Margin, SizedBox, Expanded
- Alignements : MainAxisAlignment et CrossAxisAlignment
## Séance 3 : Séance 3 : Navigation & Routes

**Durée :** 3h

### Objectifs pédagogiques

- Implémenter une navigation multi-écrans
- Transférer des données entre les vues
### Contenus

#### Système de Navigation

- Navigation impérative (Navigator 1.0) et routes nommées
- Passage d'arguments lors de la transition
- Organisation du fichier de routes principal
## Séance 4 : Séance 4 : Gestion d’état avec Provider

**Durée :** 3h

### Objectifs pédagogiques

- Différencier état local et état global
- Utiliser le package Provider pour la gestion d'état scalable
### Contenus

#### Concepts de State Management

- Limites de setState pour les applications complexes
- Introduction à Provider : ChangeNotifier, ChangeNotifierProvider, Consumer
- Injection de dépendances simple
## Séance 5 : Séance 5 : Consommation d’API REST

**Durée :** 3h

### Objectifs pédagogiques

- Communiquer avec un serveur distant via HTTP
- Gérer l'asynchronisme et le parsing JSON
### Contenus

#### Appels Réseaux

- Utilisation du package 'http'
- Modélisation des données (Classes de modèles et fromJson)
- Le widget FutureBuilder pour gérer les états de chargement/erreur
## Séance 6 : Séance 6 : Formulaires & Validation

**Durée :** 3h

### Objectifs pédagogiques

- Créer des formulaires de saisie complexes
- Valider les entrées utilisateur
### Contenus

#### Saisie de données

- Widgets Form, TextFormField et GlobalKey
- Logique de validation (Regex, longueur, champs obligatoires)
- Gestion des contrôleurs (TextEditingController)
## Séance 7 : Séance 7 : Stockage local & Préférences

**Durée :** 3h

### Objectifs pédagogiques

- Persister des données simples localement
- Gérer les préférences utilisateur
### Contenus

#### Persistance locale

- Utilisation du package SharedPreferences
- Stockage de fichiers simples sur le disque
- Cycle de vie des données locales
## Séance 8 : Séance 8 : Intégration Firebase

**Durée :** 3h

### Objectifs pédagogiques

- Configurer Firebase dans un projet Flutter
- Implémenter l'authentification utilisateur
### Contenus

#### Écosystème Firebase

- Configuration de Firebase Console et FlutterFire CLI
- Firebase Auth : Connexion email/mot de passe
- Aperçu de Cloud Firestore pour le stockage temps réel
## Séance 9 : Séance 9 : Animation & UI Avancée

**Durée :** 3h

### Objectifs pédagogiques

- Améliorer l'expérience utilisateur (UX) avec des animations
- Rendre l'application responsive et accessible
### Contenus

#### Polissage de l'UI

- Animations implicites (AnimatedContainer, AnimatedOpacity)
- Responsive Design : LayoutBuilder et MediaQuery
- Accessibilité : Sémantique et lecteurs d'écran
## Séance 10 : Séance 10 : Projet final - Event Planner App

**Durée :** 3h

### Objectifs pédagogiques

### Contenus
